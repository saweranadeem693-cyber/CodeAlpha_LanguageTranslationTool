# CodeAlpha_LanguageTranslationTool
CodeAlpha AI Internship – **Task 1: Language Translation Tool**

A web UI where you enter text, pick source & target languages, and get the translation.

## Features
- Text input, source language (with auto-detect) and target language selectors
- Google Translate API through `deep-translator` (no API key needed)
- Clear translated output display
- Optional extras: **Copy button** and **Text-to-Speech** (gTTS)

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
